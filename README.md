## 🌸 Архитектура и реализованный функционал

### 1. База данных и модели (`shop/models.py`)
- **`Category`**: Категории товаров (`id`, `name`, `slug`, `description`):
  - Монобукеты (розы, хризантемы).
  - Авторские композиции.
  - Сопутствующие подарки и услуги (упаковка, шары, открытки).
- **`Product`**: Букеты и товары (`id`, `title`, `slug`, `price` (Decimal), `image`, `category` (FK), `in_stock` (Integer для авто-снятия с публикации при 0), `composition`, `is_featured`).
- **`Order`**: Заказы клиентов (`id`, `customer_name`, `phone`, `total_price` (Decimal), `created_at`, `status` с выбором: `'Новый'`, `'В сборке'`, `'Передан курьеру'`, `'Доставлен'`).
- **`OrderItem`**: Позиции заказа (`order` (FK), `product` (FK), `quantity` (Integer), `price` (Decimal)).

### 2. Логика бэкенда (`shop/views.py` & `shop/cart.py`)
- **Динамический каталог**: Вывод доступных букетов из БД с фильтрацией по категориям, поиском, сортировкой и авто-исключением товаров с `in_stock <= 0`.
- **Серверная корзина (Django Sessions)**: Класс `Cart` для хранения товаров в сессии с поддержкой добавления, изменения количества, удаления и подсчета итоговой суммы.
- **Оформление заказа (Checkout)**: Валидация формы с полями «Имя» и «Телефон», атомарное создание заказа и позиций `OrderItem`, списание остатков и очистка корзины.
- **AJAX-функционал**: Интерактивное добавление в корзину без перезагрузки страницы и обновление счетчика в шапке.

### 3. Автоматизация и E-mail уведомления (`shop/signals.py`)
- Сигнал `post_save` на модель `Order`:
- При создании нового заказа автоматически генерирует и отправляет E-mail уведомление менеджеру магазина через встроенный модуль `django.core.mail.send_mail`.
- В письме передаются: номер заказа, данные клиента, адрес, текст поздравительной открытки, перечень позиций и ссылка в Django Admin.
- Поддерживает безопасное выполнение через `transaction.on_commit`.

### 4. Панель администратора (`shop/admin.py`)
- Настроен стандартный Django Admin с предпросмотром фото букетов, инлайнами позиций заказа (`OrderItemInline`), фильтрами по статусам и категориям, быстрым поиском.

### 5. Фронтенд (Bootstrap 5)
- Чистый, светлый и стандартный дизайн для студенческой работы.
- Адаптивная навигация (Navbar) с названием «Julia», категориями и корзиной.
- Сетка карточек товаров (Bootstrap Grid) с названиями, ценами, составом и кнопками добавления в корзину.
- Стандартный шрифт Roboto и иконки Bootstrap Icons.

## 🚀 Запуск проекта

### 1. Активация окружения и установка зависимостей
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

### 2. Настройка базы данных PostgreSQL (`.env`)
Параметры подключения к PostgreSQL настраиваются в файле `.env`:
```env
DB_ENGINE=django.db.backends.postgresql
DB_NAME=flower_shop
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5432
```

### 3. Применение миграций и наполнение демо-данными
```bash
python manage.py migrate
python manage.py seed_shop
```
> Команда `seed_shop` создаст базовые категории, букеты от главного флориста **Ткаченко Юлии Геннадьевны** и суперпользователя:
> - **Логин**: `admin`
> - **Пароль**: `admin123`

### 4. Запуск сервера разработки
```bash
python manage.py runserver 127.0.0.1:8000
```
- Витрина магазина: **http://127.0.0.1:8000/**
- Корзина: **http://127.0.0.1:8000/cart/**
- Панель администратора: **http://127.0.0.1:8000/admin/**
